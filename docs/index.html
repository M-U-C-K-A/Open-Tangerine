What’s supported — and what’s still a work in progress +

Images: PNG, JPEG, HEIC, TIFF, BMP, WebP, AVIF and SVG input routes. Availability depends on the destination codec. HEIC encoding is still being investigated; JPEG, TIFF and PDF conversion checks pass.

PDF & text: merge, split, page organization, text/image extraction, text-to-PDF and some DOCX routes. No universal Office converter or OCR.

Media & subtitles: audio/video conversion and editing; SRT, VTT and text. Many routes need a separately installed FFmpeg. Codec support varies.

Limits: native image loading is limited to 100 MB and 40 megapixels. Archive conversion is disabled. Background framing does not remove backgrounds. Redaction and metadata tools are not certified anonymization tools. Not every route has been tested end to end.

No Terminal required for the download.

  1. Download & unzip

    Choose the ZIP for your Mac from the release. Double-click it in Downloads to extract Open Tangerine.

  2. Move it into Applications

    Drag Open Tangerine into Applications. Updating? Quit the running app first, then choose Replace when Finder asks. Back up your previous copy if you want a rollback.

  3. Open it & check the menu bar

    Open Tangerine lives in the menu bar. Drag a file and use Shift for conversion, Command for tools, or Control for actions.

Apple shows “Done” and “Move to Bin”? +

Click Done, then open System Settings → Privacy & Security. If the warning says Apple cannot check the app or the developer cannot be verified, review Apple’s opening guidance. Only if you trust the exact download, use the per-app Open Anyway option in System Settings → Privacy & Security, if available.

If macOS says the app is damaged or contains malware, stop and report the exact message. Do not disable Gatekeeper or strip quarantine flags. Building from source is another option for developers.

A FEW GOOD QUESTIONS

Before you
take a bite.

Is it really free? +

Yes. Open Tangerine has no account, subscription or conversion quota. Its source is licensed under GPL-3.0-only. Optional third-party tools have their own licenses.

How do updates work? +

The app checks GitHub for a published release and opens this download page with your app version. This page tells you whether a newer version is available. Download it, quit the old app and replace it manually. It does not silently install anything.

Will it work on every Mac? +

This trial targets macOS 26 or later on Apple silicon. Intel Macs are not currently verified. Some tools depend on optional FFmpeg and available codecs.

Is this made by Tangerine? +

No. Open Tangerine is an independent project by Syntax Error Private Limited, with its own artwork. It builds on Satsuma with the original MIT attribution preserved.

Can I help build it? +

Please do. Report a reproducible issue or propose a focused improvement on GitHub. Avoid uploading private files to public issues.

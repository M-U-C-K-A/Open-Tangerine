OPEN TANGERINE / Privacy policy

Privacy policy

Last updated: 19 October 2026

This policy describes the current Open Tangerine desktop app and this download website, published by Syntax Error Private Limited.

Your files stay on your Mac

The app processes selected files locally using macOS frameworks and, for some operations, separately installed tools such as FFmpeg. We do not operate a file-upload or cloud-conversion service. Outputs are saved to your chosen destination. Temporary files may be created during processing. You control the originals and outputs.

No app account or analytics

The current app has no account system, advertising SDK, analytics or automatic crash-report upload. Diagnostic logging is off by default. If enabled, local logs can include filenames, paths, operation details and errors. Review and redact them before sharing.

Update checks and website visits

The app contacts GitHub to check published releases. Manual checks run when requested; successful automatic checks are limited to once per day. Requests do not include your files or filenames. Opening the download page from the app includes only its version in the page URL so the page can compare versions.

GitHub hosts the website, repository and releases. GitHub receives ordinary request data such as IP address, browser or user-agent information, requested URLs and request times. Its own logging, retention and privacy practices apply. See GitHub’s privacy statement. The website also requests GitHub’s latest-release information to display the download.

Optional website analytics

Current status: collection is paused while a separate analytics project is configured. No analytics banner or analytics requests run in this state. A brief setup test used our existing PostHog project; it is no longer connected. The following describes the optional integration when enabled.

Only if you choose “Allow analytics”, this website sends page views, GitHub-link clicks and download-button clicks to PostHog US Cloud. We include the page path, referring website domain, simple campaign labels, a random visitor identifier and a temporary session identifier. Full query strings, referrer paths, files, filenames, form text and screen recordings are not sent. We do not create named user profiles. PostHog receives the network request’s IP address and browser information and may derive approximate geographic location. See PostHog’s privacy policy.

Download clicks do not prove a completed download or installation. GitHub separately provides aggregate release-asset download counts and repository traffic. These measurements can include repeat requests and our own tests.

Your choice and browser storage

Analytics are off until you allow them. “No thanks” keeps them off. We also respect Do Not Track and Global Privacy Control. Use “Analytics preferences” in the footer at any time to withdraw permission; future events stop and the locally stored visitor identifier is removed. Your choice is stored in local storage for up to 180 days; when allowed, the random visitor identifier is kept with it. If browser storage is unavailable, the choice only lasts for this page. An analytics session identifier is stored in session storage while allowed and expires after 30 minutes of inactivity. No analytics cookies are set. Withdrawing permission does not automatically erase previously collected events; contact us about deletion requests.

The desktop app remains free of analytics. It saves settings and the last successful update-check time locally. Host or external-site practices are governed by their own policies. Links to Instagram and other sites take you to services we do not control.

What you choose to share

GitHub issues, pull requests and discussions can be public. Do not post private files, passwords, identifying documents or unredacted logs. If you contact us, we use the information you provide to respond and maintain the project. We do not sell information submitted to us.

Control and questions

You can remove the app and its locally stored settings, delete local logs and outputs, or stop visiting this website. For privacy questions, contact sintaxerror.pvt.ltd@gmail.com. Requests concerning GitHub-hosted account or hosting records should also be directed to GitHub. We will update this page if the product’s data practices change.
